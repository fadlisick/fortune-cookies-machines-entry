One fortune-cookie line for a machine mind: a small program that writes a single 61-character fortune to `/output/entry.txt` for make.fun's Fortune Cookies for Machines bounty.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to point the slip somewhere else, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`.
